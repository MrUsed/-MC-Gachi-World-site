# MC Gatchi World

Це недороблений сайт, присвячений моєму світу в майнкрафті,
якому вже більше 5 років. У мене була проста ідея створити сайт, 
до якого я додам будівлі і проєкти людей, які брали участь у побудові цього світу,
та розказати про це все на сайті. 
сам сайт маэ досить мынымалыстичний дизайн який був описаний через CSS 
анімації та інтирактивність картинок теж були додані завдяки CSS

Я використав
- HTML5
- CSS3 (Flexbox)
